# Dataset

This project uses the Telco Customer Churn dataset.

The dataset contains customer demographic information, account details, subscribed services, contract information, payment methods, and customer churn status.

## Dataset Source

The dataset is publicly available through Kaggle:

Telco Customer Churn Dataset by BlastChar

https://www.kaggle.com/datasets/blastchar/telco-customer-churn

## Dataset Details

- Rows: 7,043
- Columns: 21
- Target variable: `Churn`

The original dataset is not included in this repository. Please download it from the original source and place the CSV file in this `data` folder before running the notebook.
